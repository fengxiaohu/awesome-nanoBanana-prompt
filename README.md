## Getting Started

This repository contains a collection of prompts designed to help you get the most out of nanobanana models. Each prompt is crafted to be:
- 🎯 **Specific** - Clear and focused objectives
- 🔧 **Practical** - Ready to use in real scenarios
- 📈 **Effective** - Proven to produce quality results
- 🍌 **Nano-sized** - Concise yet powerful

## How to Use

1. Browse the categories below to find prompts relevant to your needs
2. Copy the prompt and customize it with your specific requirements
3. Use with your favorite AI model (Gemini)
4. Modify and iterate based on results

**Pro Tip**: Replace placeholders in `[brackets]` with your specific content!

### Creative Writing

#### photo to character figure
```
Turn this photo into a character figure. Behind it, place a box with the character's image printed on it, and a computer showing the blender modeling process on its creen. In front of the box, add a round plastic base with the character figure standing on it. Set the scene indoors if possible
```

```
Use the nano-banana model to create a 1/7 scale commercialized figure of thecharacter in the illustration, in a realistic styie and environment.Place the figure on a computer desk, using a circular transparent acrylic base
without any text.On the computer screen, display the ZBrush modeling process of the figure.Next to the computer screen, place a BANDAl-style toy packaging box printedwith the original artwork.
```

#### Merge photo
```
Take two separate photos of people and make a new image of them smiling together in a selfie
```


#### anime to live action
```
Generate a highly detailed photo of a girl cosplaying this illustration, at Comiket. Exactly replicate the same pose, body posture, hand gestures, facial expression, and camera framing as in the original illustration. Keep the same angle, perspective, and composition, without any deviation
```

#### image restore
```
Restore this black and white photograph into a high-quality, realistic, and colorful image. Preserve fine details, sharpness, and textures while ensuring natural skin tones, vibrant yet authentic colors for clothing, background, and objects. The restoration should eliminate noise, scratches, and damage while maintaining the original atmosphere and era-appropriate look. Make the result visually appealing, true to life, and historically accurate.
```

#### overlay a 3D-looking cyan wireframe mesh inside a silhouette
```
Take the silhouette of the figure and fill its interior with a cyan-colored wireframe mesh, resembling a grid-like 3D surface. The mesh should curve naturally to follow the contours of the shape, giving the impression of depth and three-dimensional form inside the flat outline. Keep the background clean so the silhouette and the cyan mesh stand out clearly. The result should look like a 3D computer graphics model shown in wireframe mode, but constrained to the original silhouette.
```



## Contributing

We love contributions! Here's how you can help make this collection even more awesome:

### How to Contribute

1. **Fork** this repository
2. **Create** a new branch (`git checkout -b amazing-new-prompt`)
3. **Add** your prompt following our guidelines
4. **Commit** your changes (`git commit -m 'Add amazing new prompt'`)
5. **Push** to the branch (`git push origin amazing-new-prompt`)
6. **Create** a Pull Request

### Contribution Guidelines

- **Quality over quantity**: Each prompt should be thoroughly tested
- **Clear categories**: Place prompts in appropriate sections
- **Descriptive titles**: Make it easy to understand the prompt's purpose
- **Include examples**: Show how to use the prompt effectively
- **Test thoroughly**: Ensure prompts work across different AI models
- **Original content**: Don't copy existing prompts without attribution

### Prompt Quality Standards

✅ **Good Prompts:**
- Clear and specific instructions
- Include context and constraints
- Specify desired output format
- Are reusable and adaptable
- Produce consistent results

❌ **Avoid:**
- Vague or ambiguous instructions
- Overly complex single-use prompts
- Prompts that produce harmful content
- Duplicate or very similar existing prompts

## Guidelines

### Best Practices for Prompt Engineering

1. **Be Specific**: The more specific your prompt, the better the results
2. **Provide Context**: Give the AI background information
3. **Set Constraints**: Define what you want and don't want
4. **Use Examples**: Show the AI what good output looks like
5. **Iterate**: Refine prompts based on results
6. **Test Widely**: Try prompts with different AI models

### Prompt Structure Template

```
[Role/Persona] + [Task] + [Context] + [Format] + [Constraints]
```

Example:
```
Act as a [professional chef] to [create a recipe] for [busy parents] that [lists ingredients and steps] and [takes under 30 minutes].
```
